# Security Policy
Toute la Physique est un site statique. Il ne collecte pas de données
personnelles et ne fournit pas de compte utilisateur ni de service serveur.
Les signalements peuvent toutefois concerner le dépôt, les scripts de build,
les dépendances locales ou le contenu publié sur le site.
## Reporting a Vulnerability
Ne publiez pas de secret, de donnée personnelle ou de détail permettant
facilement d'exploiter une vulnérabilité dans une issue publique.
Pour signaler un problème de sécurité :
Utilisez la fonction de signalement privé (« Report a vulnerability ») des
Security advisories GitHub si elle est disponible pour le dépôt.
À défaut, ouvrez une issue publique en indiquant uniquement qu'il s'agit
d'un signalement de sécurité et demandez un canal privé pour transmettre
les détails.
Merci d'inclure, lorsque c'est possible :
une description claire du problème ;
les fichiers ou pages concernés ;
les étapes permettant de reproduire le comportement ;
l'impact potentiel ;
une proposition de correction éventuelle
Au pire, envoyez un message à furtif@mail.fr
